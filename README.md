# CodeAlpha Simple URL Shortener

This project is developed as a part of the **CodeAlpha Backend Development Internship**. It is a lightweight web application built using Python and the **Flask** framework that takes a long URL and generates a unique, shortened version for easy sharing.

---

## Features
- **URL Shortening:** Accepts any long URL and generates a unique short code/link.
- **Redirection Route:** Automatically redirects users from the short URL to the original destination URL.
- **In-Memory Storage:** Uses a Python dictionary database mapping to store and retrieve URL pairs efficiently.
- **Simple UI:** Features a clean HTML interface powered by Flask templates.

---

## Prerequisites & Requirements
- Operating System: Linux (Ubuntu/Debian recommended) / Windows / macOS
- Python 3.x installed
- Pip (Python package manager)
